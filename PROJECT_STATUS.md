# Proje Durumu

## Tamamlanan başlangıç işleri

- Next.js App Router + TypeScript klasör yapısı
- Tailwind CSS responsive arayüz temeli
- Masaüstü ve mobil navigasyon
- Demo yönetim paneli
- Öğrenciler, ödemeler, yoklama, öğretmenler ve raporlar ekranları
- Supabase browser/server istemcileri
- Next.js Proxy üzerinden Supabase oturum yenileme yapısı
- `.env.example` ve güvenli anahtar kullanımı
- Supabase CLI yapılandırması
- İlk PostgreSQL migration dosyası
- Kurum bazlı veri ayrımı
- Temel roller ve Row Level Security politikaları
- Öğrenci, veli, ders, kayıt, yoklama, tahakkuk, ödeme, kasa, banka yatırımı, gider ve öğretmen çalışma tabloları
- Yerel demo seed verileri

## Bağlantı bekleyen işler

- Gerçek Supabase projesi oluşturma
- URL ve Publishable Key değerlerini `.env.local` dosyasına ekleme
- Migration dosyasını bulut veritabanına gönderme
- İlk kurum ve yönetici profilini oluşturma

## Sonraki geliştirme paketi

İlk gerçek özellik olarak Öğrenci + Veli + Ders Kaydı oluşturma akışı geliştirilecek. Bu özellik tamamlandığında demo verileri yerine veritabanından kayıt okunup yazılacak.
